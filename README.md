# Octave

Site personnel de **Octave** — pianiste (palaces, hôtels, réceptions privées) et compositeur pour l'image.

- `index.html` : page pianiste (accueil), thème sombre, bilingue FR / EN
- `compositeur.html` (aussi servie sur `/compositeur`) : page compositeur pour l'image
- `methode.html` : la méthode de travail du compositeur

## Stack
- Site statique (HTML / CSS / JavaScript)
- Bilingue FR / EN

## Développement
Ouvrir `index.html` dans un navigateur.

## Déploiement
En ligne sur Vercel — domaine principal `octave-music.com` (Gandi).
