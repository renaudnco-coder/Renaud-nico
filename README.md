# Octave

Site personnel de **Octave** — Compositeur de musique de films, chanteur et auteur.

Site vitrine cinématique, bilingue FR / EN, pensé pour présenter ses œuvres et être contacté par des réalisateurs, producteurs et marques.

## Stack
- Site statique (HTML / CSS / JavaScript)
- Bilingue FR / EN
- Sections : Œuvres · Écouter · À propos · Contact

## Développement
Ouvrir `index.html` dans un navigateur.

## Déploiement
En ligne sur Vercel — domaine principal `octave-music.com` (Gandi).
